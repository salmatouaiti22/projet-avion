# ✈️ Airline Reservation System

## 📌 Description

Système de réservation de vols développé avec HTML, CSS, JavaScript, PHP et MySQL. Il permet aux utilisateurs de réserver des billets en saisissant leurs informations personnelles, la destination, la date de voyage et le nombre de passagers.

## ⚙️ Fonctionnalités

* Formulaire de réservation
* Calcul automatique du prix (JavaScript)
* Gestion des passagers (adultes, enfants, bébés)
* Enregistrement des données dans une base MySQL
* Traitement côté serveur avec PHP

## 🛠️ Technologies utilisées

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL
* XAMPP

## 🚀 Installation

1. Installer XAMPP
2. Placer le projet dans `htdocs`
3. Démarrer Apache et MySQL
4. Créer la base de données `airline_reservation`
5. Importer les tables nécessaires
6. Ouvrir : `http://localhost/tp4/Exercice.html`
